# Sunday Line road data

Road squares for [Sunday Line](https://sundayline.app), one file per 1-degree square under `cells/`. The app loads them from GitHub Pages.

Derived from OpenStreetMap. Database: ODbL 1.0. (c) OpenStreetMap contributors. Other sources are listed on the app's About page.

These files are generated by the Sunday Line data pipeline and replaced in full on each update.
